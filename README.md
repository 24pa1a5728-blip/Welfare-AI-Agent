# Welfare AI Agent

An AI-powered welfare scheme assistant designed to help citizens discover
relevant government schemes, check their eligibility, understand required
documents, and manage their applications through a simple conversational
interface.

## Key Features

- Government welfare scheme discovery
- Rule-based eligibility checking
- Eligibility explanations
- Scheme-specific document checklist
- Application creation and management
- Application status tracking
- Regional-language friendly interaction
- AI-powered scheme guidance using RAG and agents

## Current Backend

- FastAPI
- Python
- SQLite
- Pydantic
- REST APIs

## Current Implementation

The backend currently includes PM-KISAN as the first integrated scheme,
with eligibility rules, document information, and application management.

## Project Goal

To make government welfare schemes easier to discover and apply for by
reducing the complexity of eligibility checking, document identification,
and application processes.
